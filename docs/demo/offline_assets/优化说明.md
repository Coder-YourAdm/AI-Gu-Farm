# 日新 · 前端优化版

本版沿用已有判分与助教后端，统一六页视觉与导航，增加下列功能：

- 数学诊断：可播放/拖动的回放、真实本地练习、提示与跳题、按知识点筛选记录、会话事件及 JSON 导出。
- 教法对照：学生分组筛选、增益/成本/适应度图、成本权重试算、公式校验、表格排序与 CSV 导出。
- 演化观察：四趟真实运行选择、代次时间轴、受测个体/基因详情、真实挑战观测与公开历史导出。
- 配对实验：真实 E/F 五检查点曲线、分题型得分、CSV 导出。
- 实验报告：六人均分主指标、全部运行台账、未完成计划、个体最高分补充数据、证据导出与打印。
- 六页全部支持直接打开 HTML 浏览包内快照；实时练习需要 START_DEMO 启动的本地服务。

修正的问题：取消全局滚轮/方向键抢翻页；提交归属于旧题知识点；跳题后的新题正常显示；提示请求不重复记作答；全程单请求锁与超时错误反馈；分开固定回放、模拟学生与真实模型证据；保留负适应度、并列与图表缺值；不再把留出最高分称作末代冠军。

数据来源：原 compare.json、tutor.json、result.json；新增 experiment.json 来自仓库 docs/result_brief.json。四份 history_* 来自真实运行快照，经原 app/export.py 的白名单函数导出，无测试题参考答案或鉴权字段。原 history.json 的 E_fake 数据已替换为真实 E_s42 的公开历史。旧 evolve.json 保留原文件，但新页面不使用其中 mock 数字。

教学政策按现有后端原样标注：看过提示后答对仍按半额更新掌握度；前端区分此类记录，不宣称其为独立掌握。错因是启发式线索，掌握度是模型估计，均不作确定性心理判断。

没有重新调用模型或改写正式实验成绩。所有新增操作与页面来自真实已有数据和本地状态；调整 λ 是对固定结果重评分，不是重跑模拟学生。
