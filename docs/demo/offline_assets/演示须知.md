# 日新 · 离线演示须知（优化版）

双击 START_DEMO.bat。启动器寻找可用 Python 3.11+，自动选择 8124–8134 之间的可用端口，并打开学习概览。关闭终端窗口即停止服务，无需联网和 API key。

没有 Python 也能直接打开 web/cover.html，浏览所有页面的内置证据；只有实时练习需要本地服务。

推荐演示：概览 → 数学诊断 → 教法对照 → 实验报告。侧栏另有演化观察和配对实验。

数学诊断默认展示固定回放，可播放、拖动和点击题目查看依据。切换实时练习后提交自己的答案，题目每次不同，请按题面解答，不要固定输入 1 充当正确答案。提示、跳题、重置和导出记录都可使用。格式错误或提示后的正确与独立答对分开标注。

教法对照来自模拟学生。调整成本系数只改变评分，不重新模拟；原口径为 λ=0.25。对照结果不能外推为真人提分效果。

实验报告主指标为末代六人对 20 题的平均得分。两对 E−F 分别 +0.50 / +0.17 题，均值约 +0.33 题，未观察到可靠改善。末代个体留出最高分只作补充，不能冒称末代适应度冠军。报告保留 s44 的取消/未启动记录。

滚轮和方向键保持正常浏览器行为。Alt+1…6 可以切页；顶部按钮可全屏，报告可打印。所有资源与数据本地打包，无 CDN。

发生请求错误时页面保留记录并提示，不会悄悄用假接口替代。重启服务会丢失后端内存会话，可先导出当前记录，再切回回放后重新连接。
