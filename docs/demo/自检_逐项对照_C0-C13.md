### 关于 `check_layout.js`

它读取 `window.innerWidth/innerHeight`，是**要粘进浏览器 DevTools 执行的浏览器内脚本**，不是 Node CLI。
直接 `node docs/demo/check_layout.js` 会报 `ReferenceError: window is not defined`（16:54 实测），
这是使用方式不对，**不是页面缺陷**。C13 的六格记录必须在真实浏览器里跑这个脚本后填写。
