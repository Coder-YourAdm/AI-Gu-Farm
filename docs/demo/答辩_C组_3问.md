# C 组答辩 3 问（9 / 10 / 12）

> 归属见 `docs/分工_12小时.md` §9：前端、数据来源、版权、下一步归 C。
> 要求：每问 2 句，不写长稿。被追问细节再展开，别主动加戏。

## 9. 只能做数学？

**答**：只做答案能精确复核的题型——整数、分数、有限小数；证明题、英语作文、政治大题在 `limits.refuse` 里明确拒答，页面上不出现"我可以试试"。

范围窄不是能力不足，而是**"可复核"的前提**：一旦让模型判对错，判分链就不可解释了，那正是我们不想做的事。

## 10. 记忆会不会记错？

**答**：每条记忆都带 `src` 证据链，页面上点一下就能回到产生它的原始答题事件；同一条事实再次出现时追加 `supersedes` 版本，不覆盖。

所以记错可以回放定位、可以删、可以纠；而且记忆只影响"下一题出什么、给几级提示"，**判分永远只走判分器**，记忆错了也不会把对的判成错的。

## 12. 下一步？

**答**：知识点从现在的 3 个扩到考研数学一全纲，接 30 名真实学生做 A/B，把现在的"周更"跑成真正的闭环。

这一版我们刻意先把三件事做扎实——判分可信、记忆可查、教法可对照——再谈铺量。
