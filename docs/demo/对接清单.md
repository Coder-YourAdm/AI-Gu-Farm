## 一、给 A：两份 JSON 的精确字段

放进 `web/` 即生效，**前端一行都不用改**（`tutor.html` / `compare.html` 都优先 `fetch("<文件名>")`，失败才用内联示例并挂黄条）。

### 1. `web/tutor.json`（契约 §4.3）

| 层级 | 字段 | 要求 |
|---|---|---|
| 顶层 | `profile_version` / `generated_at` | 版本号会显示在页面 `#version` |
| 顶层 | `student` | `{sid, label}` |
| 顶层 | `kcs` | **恰好 3 条**，id 必须是 `integral_definite` / `integral_improper` / `det`；每条带 `name` / `mastery` / `items` / `hint_avg` |
| 顶层 | `turns` | 对话轮；每条 `role="tutor"` 的轮**必须带 `why`** |
| tutor 轮 | `n` / `role` / `kc` / `statement` / `answer_format` | — |
| tutor 轮 | `why` | `{mastery, difficulty, last_error, memory[]}`，三个数字要真算出来，不能编 |
| student 轮 | `n` / `role` / `answer` / `verdict` / `err` / `hint_used` | `verdict ∈ {right, wrong}` |
| 顶层 | `review_plan` | `[{kc, due, reason}]` |
| 顶层 | `memory_timeline` | `[{t, text, conf, src[]}]`，`src` 要能指回真实事件 id |

**全文不得出现 `reference` 字样**（页面自检会数）。

> ⚠️ **契约示例有数学错误，别照抄**：§4.3 第 4 题写 `answer:"7/6", verdict:"right"`，
> 但 ∫₀¹(3x²−2x+1)dx = [x³−x²+x]₀¹ = **1**。§4.5 的 `/api/ask` 请求示例也写了 7/6。
> 真数据里挂一个算错的"正确答案"，数学老师一眼看穿。C 侧内联 fixture 已改成 `1`。

### 2. `web/compare.json`（契约 §4.4）

**顶层五个字段一个都不能少**：`seed`、`students`(3)、`policies`(3)、`rows`(9)、`winner{student,policy,reason}`。
A10 的验收只写「行数 = 9」，但页面图表分组、页脚种子、赢家卡片都依赖其余四个字段，只给 `rows` 会渲染出 undefined。

| 字段 | 要求 |
|---|---|
| `rows` 每行 | `student` / `policy` / `gain` / `cost` / `fitness` / `items` / `hints` / `items_to_mastery` |
| 长度 | `len(students) × len(policies)` = 3×3 = 9 |
| 精度 | `gain` / `cost` / `fitness` 保留 3 位小数 |

**口径必须按 §6.6**（页面逐行自检，差 > 0.002 标红，页脚显示「口径自检 9/9」）：

```
cost    = 0.3·(items/20) + 0.7·(hints/20)
fitness = gain − 0.25·cost
```

> ⚠️ **§4.4 示例行与公式矛盾**：示例给 `items:20, hints:14, cost:0.280`，
> 按公式应为 `0.3·1 + 0.7·0.7 = 0.790`；而且 `items=20` 时 cost 最小就是 0.300，
> **0.280 数学上不可能**。照这个示例产出，页面 9 行会全部标红。
> 请以 §6.6 的公式为准，示例只冻结字段形状。

## 二、给 B：`POST /api/ask` 与打包基线

### 1. 接口形状（契约 §4.5）

请求 `{"sid":"live01","action":"submit","answer":"1"}`，`action ∈ {start, submit, skip, hint, why, reset}`。

响应 200 必须给齐 12 个字段：`ok` / `turn` / `kc` / `verdict` / `err` / `statement` /
`answer_format` / `hint{level,text}` / `mastery{}` / `why{}` / `review[]` / `elapsed_ms`。

异常一律 `{"ok":false,"error":"Tutor: ..."}`，**不许让进程死**；只绑 `127.0.0.1`，不加 CORS；
状态落 `runs/tutor/<sid>/{events.jsonl,state.json}`，重启后 `start` 要能接着上次掌握度。

**前端唯一开关**：`web/tutor.html` 里 `var LIVE = { endpoint: null }` → 改成 `"/api/ask"`。
B 通了 C 只改这一处，其余（判分、提示、重置、失败自动回退回放）已按契约实现并自检通过。

### 2. B10 / B15 打包基线（重要）

`demo_offline.zip` **必须从合并后的 `main` 取**，不能用旧的 main：旧 main 的 `web/` 只有
`index/evolve/result` 三页，没有 `tutor/compare/cover`，且 `result.json` 是 `is_mock:true`。

必须包含：

```
web/{cover,tutor,compare}.html       # C 的三页
web/tutor.json  web/compare.json     # A 的两份真数据（缺了就挂黄条＝mock 徽章）
web/data.js  web/{history,evolve,result}.json   # 真数据，run_id = E_real_20261114

```

断网验收：`python app/serve.py --port 8123` → `http://127.0.0.1:8123/tutor.html`，
三页互跳、点开理由面板、实时连答 5 题、关掉后端自动回放。

> **`file://` 双击永远读不到 `tutor.json`**（浏览器禁止本地页面 fetch 本地 JSON），
> 只会显示内联示例。演示与截图必须走 HTTP。
