### 2. `web/compare.json`（契约 §4.4）—— 已交付 ✅

A 的 `tools/compare.py` 已产出 9 行；`python tools/check_web_contract.py --require-compare` 实测 PASS（逐行复算 cost/fitness）。

**顶层五个字段一个都不能少**：`seed`、`students`(3)、`policies`(3)、`rows`(9)、`winner{student,policy,reason}`。

| 字段 | 要求 |
|---|---|
| `rows` 每行 | `student` / `policy` / `gain` / `cost` / `fitness` / `items` / `hints` / `items_to_mastery` |
| 长度 | `len(students) × len(policies)` = 3×3 = 9，组合不重复 |
| 精度 | `gain` / `cost` / `fitness` 保留 3 位小数 |

```
cost    = 0.3·(items/20) + 0.7·(hints/20)
fitness = gain − 0.25·cost      # 用公式算出的 cost，不是 row 里那个 cost
```

> 注：3 位小数舍入带来的差（如 0.2145 → 0.214，差 0.0005）在 0.002 容差内，不算错。
> 但 **cost 必须严格等于公式值**，不能随手给数，否则 9 行全标红。
