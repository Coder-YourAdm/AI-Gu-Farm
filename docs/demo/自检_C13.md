# C13 布局自检（1280 / 1920）

> 目标：答辩投影上**不溢出、不遮挡、不糊**。
> 脚本：`docs/demo/check_layout.js`（贴进浏览器控制台，不依赖任何库）

## 一、怎么测（每页 2 次，共 6 次，约 4 分钟）

1. 双击打开 `web/cover.html`（或 `tutor.html` / `compare.html`）。
2. `F11` 全屏，`Ctrl+0` 把缩放重置到 100%。
3. 按 `F12` 打开控制台 → 把 `check_layout.js` 的全部内容粘进去 → 回车。
4. 第一行会是 `[C13] PASS` 或 `[C13] FAIL`：
   - PASS：记录一行「PASS」。
   - FAIL：`console.warn` 会逐条列出**具体元素和像素**，照它修。
5. 用 DevTools 的响应式模式（`Ctrl+Shift+M`）把视口改成 **1280×720**，重跑一次；再改 **1920×1080**，重跑一次。

## 二、通过标准

| 页面 | 1280×720 | 1920×1080 | 附加硬数字 |
|---|---|---|---|
| `cover.html` | 无横向溢出、整页不滚 | 同左 | 数字卡片 3 张 |
| `tutor.html` | 无横向溢出、整页不滚 | 同左 | 掌握度 3 条、对话流宽度 ≥ 360px |
| `compare.html` | 无横向溢出、整页不滚 | 同左 | 明细 9 行、条形组 3 组 |

六格全 PASS 才算 C13 过。**整页纵向溢出**是重点：三页都改成了 flex 竖排（C6），面板内部滚动、页面本身不该出现滚动条——如果这里报错，先 `Ctrl+F5` 清缓存，再检查是不是又有人加回了 `calc(100vh - ...)`。

## 四、常见 FAIL 与处理

| 报错 | 多半原因 | 怎么修 |
|---|---|---|
| 页面横向溢出 | 某个固定宽度 > 视口，或长英文/公式不换行 | 找到 warn 里的元素，加 `min-width:0` 或 `overflow-wrap:anywhere` |
| 整页纵向溢出（tutor） | 提示条出现 + 又用回了 `calc(100vh - 57px)` | 确认 `body` 是 `display:flex;flex-direction:column`、`main` 是 `flex:1` |
| 整页纵向溢出（cover） | 720 高度下 hero + 三个数字 + CTA 加起来超了 | 缩 `h2.hero` 的 clamp 下限或 `.nums` 的 `margin-top` |
| 元素越界（`#turns` 等） | 三栏 grid 在 1280 下挤压 | 检查 `main` 的列宽，必要时把右栏 330px 降到 300px |
| 字号过小 | 有 `font-size:9px` 这类标注 | 抬到 ≥ 10px（投影上 9px 基本看不见） |
| 提示条可见 | `web/tutor.json` 没到位 | 不是 bug；但**正式截图前必须补数据**（见操作单第 0 节） |

## 五、和 C11 的关系
