## 1. 路线选择：为什么不用「把截图丢给 AI 生成视频」

结论先写死，避免临场改主意：

| 路线 | 判断 |
|---|---|
| 裸 Codex 直接出视频 | **不行**。Codex 是编码 agent，只读图不渲染帧 |
| Codex + 第三方视频 skill（Kling / Sora / Seedance 付费 API） | **能出片但不该用**。生成模型会重绘界面上的文字、表格与判分数字 |
| **真人录屏 + 截图转场 + AI 仅片头** | ✅ **采用** |

**理由不是技术，是保住卖点**：本项目主张「我们不让模型给自己打分」
「数字都能在仓库里复核」，C11 操作单明确要求「不要 P 掉黄条……
P 图被问一句就穿」。AI 重绘界面就是一次全自动 P 图，
把 `0.116 / +0.33 / 612 tests` 变成模型编的鬼画符，等于自毁诚实人设。

> **唯一自留地**：AI 生成只用于 **3–5 秒片头氛围**，画面里**不出现任何界面与数字**。
> 「让截图缓慢推拉」≠「让 AI 重新画一遍截图」——前者零幻觉，后者不可用。

## 2. 90 秒主体分镜（照 C11 念，此处只补旁白与画面纪律）

| 时间 | 画面 | 操作 | 字幕 / 口播 |
|---|---|---|---|
| 0–8s | 封面 | 静止 | 「这是三个数字：可教学题、知识板块、教法对照组」 |
| 8–22s | 诊断页 | 点第 1 题题面 → 理由面板展开 | 「不只判对错，还能说清为什么选这道题」 |
| 22–35s | 诊断页 | 点左侧知识点 → 对话流过滤 → 再点取消 | 「点一个知识点，整段对话按它过滤」 |
| 35–45s | 诊断页 | 点记忆条目 → 展开 `src` | 「每条记忆都带证据链，能回到产生它的那次答题」 |
| 45–60s | 诊断页 · 实时 | 切「实时」，交 `0` 两次，看提示 L0→L2 | 「学生打一个答案，提示一级一级加」 |
| 60–72s | 诊断页 · 实时 | 交 `1` → 判对、掌握度跳升 → 重置 | 「答对，掌握度立刻更新」 |
| 72–85s | 对照页 | 切「增益 → 成本 → 适应度」 | 「九组对照，三个指标切换看」 |
| 85–90s | 对照页 | 静止 | 「数字都能在仓库里复核」 |

### ⚠️ 数字口径提醒（105 / 125 都对，别混念）

C11 分镜念的是「**105** 道可教学题」，README 硬核数字表写的是
「**125** 道自造题，签名全部互斥」。**两个数都真实，是不同口径，不是过时**：

| 数 | 口径 | 来源 |
|---|---|---|
| **105** | 可用于教学的题 = 校准 20 + 共同开发 80 + 挑战 5 | `web/app.js` 的 `overview()`，`web/experiment.json` 的 `datasets` |
| **125** | 自造题总池 = 上面 105 + **留出评测 20** | `README.md` §硬核数字、`validate_task 125/125` |

留出评测那 20 道是考试用的，不进教学，所以页面显示 105。

- 旁白念封面时**说 105**（跟画面一致）；讲题池规模时才说 125；
- 录之前对着 `web/experiment.json` 的 `datasets` 核一次，别把两个数混在一句话里；
- 同理，别把 `is_mock` 时期的旧数字念进片子（`web/result.json` 现已 `is_mock: false`）。

## 3. 录屏执行（不需要 ffmpeg）

### 3.1 起服务

优先用队友做好的离线包（自带一键启动、自动找 8124–8134 可用端口）：

```bat
:: 解压 demo_offline.zip 到「路径里没有空格」的目录，然后
START_DEMO.bat
```

或直接从仓库起（正式演示口径）：

```bash
python app/serve.py --port 8124 --allow-tutor
# 浏览器开 http://127.0.0.1:8124/cover.html
# 注意：用 http://，别用 file:// 双击（浏览器会拦本地 fetch）
```

> 端口说明：C11 老版本写 8123，B 的上台清单与演示须知现在统一按 **8124**（启动器自动找 8124–8134）。
> 两个端口都能跑，**别同时起两个服务**。

### 3.2 录

- 工具：`Win + G`（Xbox Game Bar，系统自带）或 OBS；
- **60fps，只录浏览器窗口**，不录全屏（防地址栏、任务栏入镜）；
- 不录声音也行，现场口播或后期配字幕；
- 分辨率按 **1920×1080**，与 `*_1920.png` 截图一致。

### 3.3 命名与体积

`demo_90s.mp4`，**≤ 30MB**，放桌面备用（B 的上台清单第 1 节要求随手可切）。

## 4. 片尾 / 转场：用现成截图，不生成

`docs/demo/shots/` 里可直接用的素材：

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `cover_1920.png` | 1920×1080 | 片尾定格 / 章节卡 |
| `tutor_1920.png` | 1920×1080 | 诊断页补充 |
| `tutor_why_1280.png` | 1280×720 | 理由面板特写 |
| `compare_1920.png` | 1920×1080 | 对照页定格 |
| `rixin-cover.png` 等 3 张 | 1440 宽长图 | **长图，适合竖版社媒，不适合横版主片** |

**做法**：在剪映 / Premiere / 甚至 PPT 里给静帧加 3–5% 的缓慢推拉（Ken Burns），
叠字幕，导出 16:9。这是「让图片动起来」，**不调用任何生成模型，数字一个不变**。
本机没有 ffmpeg，所以不写 ffmpeg 命令；若后续装了，可用
`zoompan` 滤镜批量生成静帧片段，但**不是必需**。

## 5. 15 秒宣传旁白（片头之后接主体，或单独做短版）

> 「AI 教育不缺会讲题的模型，缺的是敢让老师签字的判分。
> 我们把对错交还给本地精确算术，0 浮点、零次让模型当裁判。
> 模型只负责把下一步讲成人话——所以可换、可断网、数据不出校门。
> 这不是又一个刷题 App，是一层**能被追责的可信基础设施**。
> 612 条测试，2640 次留出评测，每一个数字都能在仓库里复核。」

字幕建议逐句上，别整段糊在画面上；**数字必须与画面里的真实值一致**。

## 6. AI 片头提示词（可选，3–5 秒，唯一允许用生成模型的地方）

> 用途：仅做氛围转场，**画面里不出现任何 UI、文字、数字、公式、表格**。
> 若时间紧，直接跳过这段，用 `cover_1920.png` 淡入即可，效果一样稳。

**给图生视频 / 文生视频模型的提示词**：

```
A slow, calm camera push-in over a warm paper-textured desk at dawn.
Soft natural light, a closed notebook, a pencil, a cup of tea.
Muted warm beige and deep teal palette, no text, no letters, no numbers,
no screens, no UI, no logos, no people. Gentle shallow depth of field,
subtle dust motes in the light. Cinematic, quiet, academic. 4 seconds, 16:9.
```

**负面约束（务必带上）**：`no text, no watermark, no interface, no charts, no math symbols`。

> 为什么不拿 `cover_1920.png` 去图生视频：那会把封面上的三个统计数字重绘掉。
> 片头用「空白桌面」这类无信息画面，重绘了也无伤大雅。
