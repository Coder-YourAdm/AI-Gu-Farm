## 0. 前置条件（不满足就别截图，截了也得重来）

- [ ] `web/tutor.json` 存在。**否则诊断页会挂「内联示例数据」黄条**——验收里"无 mock 徽章"这一条直接不成立。
- [ ] `web/compare.json` 存在。否则对照页同样挂黄条。
- [ ] 一键自检通过：`powershell -NoProfile -ExecutionPolicy Bypass -File docs/demo/check_all.ps1` → 末尾 `ALL CHECKS PASS`
- [ ] **合并 / 发布前再用 `-Strict` 跑一次**（`... -File docs/demo/check_all.ps1 -Strict`）：浏览器起不来时默认会 SKIP，`-Strict` 会让它变成硬失败，避免"以为验过了"
- [ ] 浏览器 100% 缩放、F11 全屏、关掉书签栏与所有扩展（扩展图标会入镜）
- [ ] 屏幕分辨率 ≥ 1920×1080（截图按 1920 出，投影最稳；1280 只用于"低分辨率也不溢出"的自检）

> 如果 A 的数据到不了：**不要 P 掉黄条**。正确做法是截图保留黄条、答辩主动说"这页现在跑的是内联示例，数据结构与契约一致，真数据一到自动切换"。P 图被问一句就穿。

## 2. 90 秒录屏（分镜，照念即可）

工具：`Win + G`（Xbox Game Bar，系统自带）或 OBS；60fps；只录浏览器窗口；不录声音也行（现场讲）。

| 时间 | 画面 | 操作 | 一句话（可不说，现场口播） |
|---|---|---|---|
| 0–8s | 封面 | 静止 | "这是三个数字：105 道可教学题、3 个知识板块、9 组教法对照。" |
| 8–22s | 诊断页 | 点第 1 题题面 → 理由面板展开 | "它不只判对错，还能说出为什么选这道题：掌握度、难度、上次错因。" |
| 22–35s | 诊断页 | 点左侧「定积分」→ 对话流被过滤；再点一次取消 | "点一个知识点，整段对话按它过滤。" |
| 35–45s | 诊断页 | 点记忆条目 → 展开 `src` | "每条记忆都带证据链，点开能看到是哪次答题产生的。" |
| 45–60s | 诊断页 · 实时 | 切「实时」，输入 `0` 交两次，看提示从 L0 升到 L2 | "实时模式下，学生打一个答案，提示会一级一级加。" |
| 60–72s | 诊断页 · 实时 | 输入 `1` → 判对、掌握度跳升；再点「重置」 | "答对，掌握度立刻更新；重置回到第一题。" |
| 72–85s | 对照页 | 切「增益 → 成本 → 适应度」 | "九组对照，三个指标切换看，页脚自带口径自检。" |
| 85–90s | 对照页 | 静止 | "数字都能在仓库里复核。" |

**录完检查**：全程无黄条、无地址栏、无 `reference`、无卡顿黑屏；文件 ≤ 30MB，命名 `demo_90s.mp4`。
