# 三页交互说明（演示时照着点）

> 打开方式：`python app/serve.py --port 8124 --allow-tutor` 后访问 `http://127.0.0.1:8124/cover.html`
> （8123 常被旧预览进程占用；`--allow-tutor` 才会把「实时」接到真后端）
> 直接双击 `file://` 也能开，但读不到 `tutor.json`，会挂"内联示例数据"黄条——正式演示/截图请不要双击。

## 一、三个入口（顶栏，三页都有）

`封面` ↔ `诊断` ↔ `对照`，当前页高亮。任何一页都能直接跳，不会丢上下文。

## 一·二、切屏方式（只认明确操作，滚动不会切屏）

> 刻意**不把滚轮/触控板滑动**绑成切屏：演示时一不小心就会划走。切屏只有三种明确动作。

- **点击顶栏导航**：封面 / 诊断 / 对照，当前页有常驻下划线
- **点击左侧圆点**：页面左边三个小圆点，鼠标移上去显示板块名，点一下直接跳
- **键盘**：`→` / `PageDown` 下一屏；`←` / `PageUp` 上一屏
- 过渡：旧页淡出并朝切换方向位移（下一屏向上、上一屏向下），新页从反方向逐层上浮
- 顶部 2px 砖红进度条表示当前第几屏；封面底部提示「点导航切换 · ← →」
- 系统开启"减少动态效果"时只缩短过渡，切屏操作不受影响

## 二、诊断页：四处可点

| 点哪里 | 会发生什么 | 讲给观众的一句话 |
|---|---|---|
| 对话里的**题面气泡** | 右侧「为什么是这道题」展开，显示**掌握度 / 题目难度 / 上次错因**三个数字 + 相关记忆 | "它每出一道题，都能说出三个数——不是随机挑的。" |
| 左侧**知识点条**（定积分/反常积分/行列式） | 高亮该条，中间对话流只留下这个知识点的问答；再点一次取消 | "点一个知识点，整段对话按它过滤。" |
| 左侧**记忆条目** | 展开 `src`，列出这条记忆来自哪几次答题（`evt_xxxx`） | "每条记忆都有证据链，能追到原始事件。" |
| 顶部 **回放 / 实时** 开关 | 回放=读预置的 8 轮对话；实时=接真后端：打答案由 `POST /api/ask` 判分 | "它不是一个视频，你可以上手答一题。" |

### 实时模式（切到「实时」后）

- 输入框打答案（整数 / 分数 / 小数），按 **Enter** 或点「提交」
- **只想展示效果**：切到「实时」后点 **一键演示**，它自动走完「重置 → 答错看错因与提示 → 再提示 → 重置 → 给我答案并照答（半次）→ 为什么」六步，约 10 秒，不用记按钮；演示中按钮显示进度，结束后可继续手点
- 其余五个按钮：**我不会**（按放弃处理）、**再提示一点**（L0→L4 逐级升）、**为什么给我这道题**（刷新理由面板）、**给我答案**（演示用：调只读接口 `/api/reveal` 显示当前题答案；看过答案后，紧接着答对只算半次独立答对）、**重置**（回到第 1 题、掌握度归 20%）
- 连交 5 次错答案，提示会一级一级升到"直接给答案"；答对后掌握度条会跳、自动换下一题
- **断服务/接口不可用时会自动切回回放并弹黄条**，不会白屏

## 三、对照页：两个交互

| 点哪里 | 会发生什么 |
|---|---|
| 顶部 **增益 / 成本 / 适应度** | 3×3 条形图按该指标重画（条形长度变），右上角提示语跟着换 |
| 读表格 | 9 行明细，`✓` 标出每档学生的最优教法；底部有一行「口径自检 9/9」说明这九个数算得通 |

## 四、封面：两个按钮

- 「看一次诊断」→ 直接进诊断页
- 「看 9 组对照」→ 直接进对照页

## 五、演示动线建议（90 秒版）

封面讲三个数字 → 诊断页点一条题面（出三个数）→ 点一个知识点（过滤）→ 点一条记忆（看 src）→ 切实时、交两个错答看提示升级、交一个对答看掌握度跳 → 重置 → 对照页切三个指标 → 收尾。

## 六、三个"别踩"

1. 别用 `file://` 演示真数据（见开头）。
2. 实时模式下输入框才有；回放模式没有输入框是正常的。
3. 点题面没反应？先确认点的是**题目气泡**（左边那条带题目文字的），不是学生答案气泡。
