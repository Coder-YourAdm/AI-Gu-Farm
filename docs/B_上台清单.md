## 0 一句话演练

> 六个 prompt 互相出题、互相解题，判分由本地精确算术完成。二十代之后，进化组比冻结组
> 平均高 0.33 题（满分 20）——方向为正，但幅度在噪声内，所以我们报告**未观察到可靠改善**。
> 真正硬的结论是挑战题：5 阶行列式连续六代六人全错，4 阶最高只到 2/6。

## 1 上台前 5 分钟（按顺序打勾）

- [ ] 解压 `demo_offline.zip` 到桌面，路径里**不要有空格**；
- [ ] 双击 `START_DEMO.bat`，浏览器自动打开 `cover.html`；
- [ ] 依次开 `tutor.html` → `compare.html` → `result.html`，确认：
  - 无「内联示例数据」黄条；
  - `result.html` 无红色 mock 标；
  - 地址栏是 `127.0.0.1:8124`，不是 `file://`；
- [ ] `tutor.html` 切一次「实时」，输入 `0` 交两次，看到提示升级后点「重置」；
- [ ] 备好 90 秒录屏（`demo_90s.mp4`）放在桌面，随时可切。

> 断网没关系：四个页面与实时判分全走本地，不调模型。只有 `tutor.html` 的实时模式在
> 后端不可达时会自动回放——那是演示的降级路径，不是故障。

## 2 四个页面怎么讲（每页 20 秒）

| 页面 | 动作 | 口播 |
|---|---|---|
| `cover.html` | 静置 | 三个数字：可教学题、知识点、教法对照组 |
| `tutor.html` | 点题面 → 理由面板；切实时交 `0`、再交 `1` | 判完能说清「为什么给我这道题」：掌握度、难度、上次错因 |
| `compare.html` | 切「增益 / 成本 / 适应度」 | 三套教法 × 三档学生，成本口径写在页脚 |
| `result.html` | 静置，指 E/F 与挑战 | 留出评测的真实数字；挑战 X04 连续 0/6 |
