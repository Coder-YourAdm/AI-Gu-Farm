## 0. 先砍范围（这一节最重要）

完整方案是 24 小时的量，12 小时只能做骨架。**砍掉的不是质量，是覆盖面**：

| 项 | 完整方案 | 12 小时版 | 理由 |
|---|---|---|---|
| 知识点 | 8 个 KC | **3 个**：定积分 / 反常积分 / 行列式 | 现有 4 族模板直接映射，零新增数学代码 |
| 新模板族 | +4 族 | **0 族** | 每族 45–60 分钟 × 4 = 3 小时，换不来演示效果 |
| 策略演化 | 6 个体 × 3 代 | **3 套手写教法 × 1 轮对照** | 引擎改造要 ≥4h；对照实验能给出同样的"选出来的"证据 |
| 模拟学生 | 3 档 | **3 档（弱/中/强），但只在离线跑一次** | 演示不需要实时 |
| 真人案例 | 有 | **不做** | 12 小时内做真人只会得到 n=1 的噪声 |
| 前端 | 3 页 + 后台 | **3 页 + 静态 JSON，不调后端** | 见下条，这是最大的降险决策 |

**关键决策：前端不调后端，只读静态 JSON。**

理由：现场网络、进程、端口任何一个出问题，演示就死。改成"C 的前端读 A/B 产出的 `web/tutor.json`"，交互全在浏览器里，**拔网线也能点**。命令行 live 跑一次作为可选加分项，失败不影响主流程。

## 5. 前端信息架构（C 照这个做，不要自由发挥）

| 页面 | 区块 | 数据 | 必须有的交互 |
|---|---|---|---|
| `cover.html` | 标题 + 一句话 + 三个数字（3 个 KC / 439 测试 / 4 组对照） | 静态 | 无 |
| `tutor.html` 左栏 | 对话流（题面、学生答、判定、提示） | `turns[]` | 滚动到底；判定色用**对=绿 / 错=红**（学习场景，与股市红涨绿跌无关，别照搬） |
| `tutor.html` 右上 | 3 条掌握度横条 | `kcs[]` | 切换 KC 高亮 |

| `tutor.html` 右下 | 记忆时间轴（竖向 3 条） | `memory_timeline[]` | 展开原始事件 id |
| `tutor.html` 底部 | 复习计划一行 | `review_plan[]` | 无 |
| `compare.html` | 3 套教法的 gain / cost / 题量 | `compare.json` | 条形图切换指标 |

**样式纪律**：沿用现有 `web/` 的字体与配色，不引外部 CSS/JS（断网要求）。单文件，内联。
