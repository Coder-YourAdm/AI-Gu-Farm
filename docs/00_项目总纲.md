## 0. 一分钟读完

**一句话**：让 6 个 prompt 互相出题、互相残杀，演化出一套最会教的教法；
把这套教法**冻结成文件**，配上本地精确判分、掌握度估计与带证据的记忆，
交给一个 AI 去服务真实学生。

**为什么不是两个项目**：前面证明「方法能被演化、能被测量」，后面证明「方法能落到人身上」。
中间那条唯一的接口是 `best_profile.json`——训练期重、慢、可复现；
运行期轻、快、**拔网线也能演**。

**赛道怎么呼应**：三层「日新」——
① 群体层：prompt 个体 20 代更替（训练期，离线）；
② 教法层：profile 每周离线重训一次（周更）；
③ 认识层：学生对每个知识点的掌握度**每答一题就变**（秒更）。
答辩一句话：**「教法周更，认识秒更。」**

## 1. 两阶段架构

| | 阶段一 · 练功（已完成） | 阶段二 · 服务（可演示，部分施工中） |
|---|---|---|
| 谁在变 | 6 个 prompt 个体 × 20 代 | 掌握度、题目难度、记忆强度、复习排期 |
| fitness | 出题区分度 + 解题正确率 | 学生增益 − 0.25 × 交互成本 |
| 产物 | 冠军个体 / 冻结协议 | `best_profile.json`（可 diff、可回滚） |
| 依赖 | 模型（出题 / 解题） | **本地引擎**，模型只负责把下一步说成人话 |
| 断电能否演示 | 不能 | **能**（回放 + 本地接口） |

```
[训练期 · 重 · 离线]              [产物]              [运行期 · 轻 · 每句话]
app/run.py + executor.py   →   best_profile.json   →   app/tutor/ + app/student/
  6 个体 / 20 代 / 精确判分        冻结、带 evidence       judge / BKT / 五级提示
                                                            ↓
                                              web/{cover,tutor,compare}.html
```

**关键纪律**：运行期只读 profile，不读 `runs/`、不读 `history.jsonl`、不读 `config.json`。
这一条同时买到三件事：学生端不可能泄漏参考值、换模型不影响产品、旧版本存档即回滚。

## 2. 技术护城河（八条硬决策）

1. **不用 LLM 当裁判。** 判分走本地 `Fraction` 精确算术，四族题（多项式积分 / Γ 型反常积分 / 高斯奇次矩 / Bareiss 行列式）全有闭式解。同一道题，任何人、任何时候、任何模型算出的答案都一样。
2. **三态判定。** `judge()` 返回 `right / wrong / unanswered`；把「拒答」混进 `wrong`，学到的规则方向就是错的。格式错一律 `unanswered`，两者都计 0 且占分母。
3. **白名单下发。** 模型只拿 `type / statement / answer_format` 三个键；`reference`、`template`、`params`、历史成绩一个都不给。禁止 `json.dumps(task)` 直接发。
4. **入口先拒绝。** 正则 → 位数 ≤64 → 指数 ≤30，全部做完才调 `int` / `Decimal`；9000 字符响应在 `json.loads` 之前就拒。先限定文法再转换，挡住 `Fraction("1e999999")` 这类构造。
5. **升级必须挣来。** 学生说「我懂了」不算，必须无提示、独立、换一道同 KC 不同参数的题再对一次；靠提示答对只花成本、不产生增益。
6. **fitness 减成本项。** 只加增益，演化一定选出「无限提示、把答案嚼碎」的策略。减掉 `0.25 × 交互成本`，才选得出「话少而准」。
7. **单变量实验。** 3 套教法 × 3 档模拟学生，题目 / 判分 / 随机流完全相同，只改提示策略；每题用 `(seed, level, 题号)` 派生独立随机流，避免提示消耗随机数让后续抽签错开。
8. **断网可演。** 前端单文件内联、零外链；回放读静态 JSON，实时可走本地接口。演示不押注网络、端口或模型心情。

## 3. 题域与数据

| 项 | 值 |
|---|---|
| 题集 | **125 道**：calibration 20 / common_dev 80 / challenge_pool 5 / holdout 20，签名 125 个互斥 |
| 题面 | 8 条与规格附录 A **逐字对齐**；`coeffs` 是升幂（常数项在前） |
| 知识点（当前 3 个） | 定积分 `poly` / 反常积分 `gamma`+`gaussian_odd` / 行列式 `det` |
| 扩充路线 | 完整方案 §8 给出 8 个 KC，新增一族成本 ≈ 20 行 + 20 条测试 + 一次 SymPy 交叉，45–60 分钟 |
| 答案形态 | 整数或分数，数字一律字符串保存，避免大整数被 JSON 变 float |
| 边界 | 元素 ∈ `[-9,9]`；proof / 作文 / 政治大题**明确拒答** |

> 「只做答案能精确复核的题」是判分可信的前提，不是能力缺陷。
