## 6. 可选模块：把回放页升级成「真能打字」的前端（2 小时，T+5:30–7:30）

默认方案里 `tutor.html` 是**回放页**（读 `web/tutor.json`），人只能点、不能输入。
如果要做"人真的在跟系统答题"的交互，加一层 **L1 实时接口**——**不需要模型**，因为判分、归因、提示全是本地引擎。

### 6.1 为什么这次值得做

| 好处 | 说明 |
|---|---|
| 答辩张力完全不同 | 评委可以自己上手打一个答案，系统当场判对错、给提示 |
| **断网也能交互** | 判分走 `executor.judge()`，提示走 `hint.render()`，全程本地 |
| 风险可控 | 只是给已有 `serve.py` 加一个 POST 分支；挂了就退回回放页 |

### 6.2 接口（B 负责，45 分钟）

`app/serve.py` 已经有 `do_POST` 与 `_json()`，加一个分支即可：

```
POST /api/ask
{"sid":"demo","action":"start|submit|skip|hint|why|reset","answer":"7/6"}

200 {
  "ok": true, "turn": 3, "kc": "integral_definite",
  "verdict": "wrong", "err": "calc",
  "statement": "计算定积分 ∫_{0}^{1} …。", "answer_format": "…",
  "hint": {"level": 1, "text": "…"},
  "mastery": {"integral_definite": 0.28},
  "why": {"mastery": 0.31, "difficulty": 0.35, "last_error": "…", "memory": ["evt_0031"]},
  "review": [{"kc": "integral_definite", "due": "2026-11-17"}]
}
```

- `action=start` 出新题；`submit` 交答案；`skip` 记 `giveup`；`hint` 手动升一级；`why` 只要理由；`reset` 清空该 `sid`。
- 状态落盘：`runs/tutor/<sid>/{events.jsonl,state.json}`；**服务重启后能接着答**。
- 必须绑 `127.0.0.1`，不加 CORS，key 只在服务端（L2 才需要）。
- **坑**：`serve.py` 里有 `os.chdir(WEB)`，所以 Tutor 内部路径必须用 `ROOT` 绝对路径，不能用相对路径。

### 6.3 前端（C 负责，75 分钟）

在 `tutor.html` 上加一条输入栏：

| 控件 | 行为 |
|---|---|
| 输入框 + Enter | `POST /api/ask {action:"submit", answer}` |
| 「我不会」 | `action:"skip"` |
| 「再提示一点」 | `action:"hint"` |
| 「为什么给我这道题」 | 展开 `why` 面板（不请求，直接用上一轮返回的 `why`） |
| 「重置」 | `action:"reset"`，二次确认 |

要求：请求失败时**不白屏**，弹出"实时模式不可用，切回回放"并自动 load `web/tutor.json`。这一条是保命的。

### 6.4 两个模式共存

页面顶部放一个开关：**回放（默认）/ 实时**。

- 回放：读 `web/tutor.json`，零依赖，断网可演；
- 实时：调 `/api/ask`，需要 `python app/serve.py --allow-tutor` 启动。

演示时默认停在回放，评委想上手时按一下切实时。**这样即使接口出问题，主线不掉。**

### 6.5 时间从哪来

从"录屏（40 分钟）"和"对照页打磨（30 分钟）"里挪 70 分钟，A 补上集成验收 30 分钟。若 T+7:30 还没通，**直接放弃实时**，不影响降级顺序里的任何一项。
