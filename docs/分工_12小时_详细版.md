## 5. 实时层验收脚本（A15/B13 共用）

```bash
# 起服务（演示前一天都用这个命令）
python app/serve.py --port 8123 --allow-tutor

# 1. 出新题
curl -s -X POST http://127.0.0.1:8123/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"sid":"live01","action":"start"}' | python -m json.tool

# 2. 交一个错答案，应返回 verdict=wrong + hint.level=0
curl -s -X POST http://127.0.0.1:8123/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"sid":"live01","action":"submit","answer":"0"}' | python -m json.tool

# 3. 连交五次错答案，hint.level 必须单调升到 4 并封顶
# 4. 重置后 action=start 应回到难度最低的题
# 5. 关掉服务再点页面：必须提示"实时模式不可用"并自动切回放
```

**必须同时满足**：`runs/tutor/live01/` 里有 `events.jsonl` 且每次提交多一行；服务重启后再 `start` 能接着上一次的掌握度。

## 7. 降级顺序（越靠前越先砍）

1. 记忆时间轴（页面静态化）
2. 实时层的「再提示一点 / 重置」（只留提交）
3. 对照页（数字挪进答辩稿）
4. 复习计划（口头说）
5. 提示梯度降到 3 级（restate / step / answer）
6. 模拟学生从 3 档降到 2 档
7. 录屏（只留截图）

**永远不砍**：`why` 的三个数字、判分可复核、`limits.refuse` 的诚实声明、**回放模式**。

> 注意降级顺序里"实时层"排第 2——意思是**它可以先瘦身，但不要整块消失**，因为评委上手打一个答案的那 30 秒，比多讲一页 PPT 值钱。
