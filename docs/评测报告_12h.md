## 1. 一句话结论

在 3 档模拟学生 × 10 题上，**`loose` 跨档平均 fitness 0.116 最高**，
`answer_only` -0.035 垫底。也就是说：按「学生增益 − 0.25×交互成本」选教法，
选出来的是**克制提示**而不是「一错就摊答案」——成本项确实在起作用。
`winner.student = strong` 只是该教法下表现最好的一档，不是评选对象。

## 2. 实验设计：一次单变量实验

| 九组完全相同 | 唯一改变 |
| --- | --- |
| 题目（`data/calibration.json` 交错取 10 题，覆盖 3 个 KC） | `app/tutor/policy.py` 的提示策略：给几次、从第几级开始 |
| 判分（`executor.judge`，本地精确算术） | |
| 掌握度（`bkt.mastery_of`）与随机流（按 `seed/档位/题号` 派生） | |

两条设计决定值得单独说：

1. **升级必须挣来**：只有「无提示的第一次答题」进 BKT，提示后的重试
   只消耗成本、不产生增益。否则直接给答案就能把掌握度刷上去。
2. **每题独立随机流**：三套教法提示次数不同，若共用一条 RNG，
   第 2 题之后的抽签会错开，gain 的差异就来自随机数而不是教法。
   改成按 `(seed, level, 题号)` 派生后，同一档学生三套的 gain
   **逐位相同**（weak 0.007 / mid 0.200 / strong 0.543），差异 100% 落在 cost 上。

`hints` 是**加权提示次数**：第 L 级提示按「暴露 L+1 份信息」折算
`hint_weight(L) = L+1` 次，所以第 4 级（给完整解法）一次算 5 次。
`cost = 0.3·items/20 + 0.7·hints/20`、`fitness = gain − 0.25·cost`
严格按契约 §6.6，未改一个系数。

## 5. 三个诚实声明

1. **这是模拟学生，不是真人**。`SimStudent` 只是三档固定答对率
   （0.25 / 0.50 / 0.75）+ 受控随机数，不能外推到真实学习者。
2. **样本极小，不报 p 值**。n = 3 档 × 10 题，只报原始配对差与均值，
   不做任何显著性主张——这个样本量报 `p < 0.05` 是不诚实的。
3. **题域只覆盖 3 个可精确判分的知识点**（定积分 / 反常积分 / 行列式）。
   证明题、作文、政治大题明确拒答，这是设计选择，不是能力缺陷。

另外两条要主动说清：

- `gain` 在三套教法间**完全相同**，这不是「实验没测出差异」，而是我们
  刻意把能力观测固定在无提示第一次答题、不在增益里重复计算提示的价值
  （避免双重计数）。教法的效果通过成本项体现，所以排序由 cost 决定。
- `hints` 加权后可超过 20，`cost > 1` 会出现。这是**有意的惩罚项**，
  基数仍按契约固定为 20，没有为了好看去调分母。
