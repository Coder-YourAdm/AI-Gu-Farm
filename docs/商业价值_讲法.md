# 商业价值 · 讲法（30 秒 / 2 分钟 / 评委三问）

> **用途**：答辩、路演、宣传片旁白的统一口径。
> 配 [`docs/答辩_12问.md`](答辩_12问.md) 的「加问」段使用；
> 分镜与旁白落地见 [`docs/demo/宣传片_制作脚本.md`](demo/宣传片_制作脚本.md)。
>
> **本文件不编任何市场数据**。全仓原本没有商业化表述，这块是空白，讲好了是纯加分；
> 但一旦编 TAM / 用户数 / 营收预测，评委一问数据来源就穿——
> 跟 C11 操作单里「不要 P 掉黄条」是同一个道理。
> 气势靠**结构 + 可复算的真数字**，不靠形容词。

## 0. 先定调：一句话定位

> **不卖「AI 家教」，卖「AI 教育里最缺的那层可追责的判分与评测基础设施」。**

**钩子**：AI 教育不缺会讲题的模型，缺的是**敢让老师签字的判分**。

市面上所有 AI 家教卡在同一处：模型自己判对错，判错了没人能追责，
所以学校不敢采购、老师不敢用、家长不敢信。我们把判分从模型手里拿回来，
用本地精确算术变成**可复核、可回放、可追责**的事实。

**别讲成「又一个考研数学 App」**——那个赛道红海、天花板低、还要真题库和名师资源，
一问就露馅。助教只是第一个跑通的**样板场景**，护城河在评测流水线，不在题库。

## 1. 30 秒电梯版（可直接背）

> 「市面上 AI 家教几百个，但没有一个能回答『这题判错了谁负责』。
> 我们把判分从大模型手里拿回来，用本地精确算术做，0 浮点、0 次让模型当裁判——
> 对错可复核、可回放，责任可界定，这是学校敢采购的前提。
> 模型只剩一件事：把下一步讲成人话，所以模型可换、每次判分零调用成本、
> 断网也能跑，数据不出校门。
> 我们交付的不是又一个刷题 App，是**可信判分与教法评测基础设施**；
> 助教只是第一个跑通的样板。612 条测试、2640 次留出评测，都在仓库里，随时能复算。」

## 2. 2 分钟答辩版（五段，按这个顺序）

| 段 | 讲什么 | 时间 | 可指的证据 |
|---|---|---|---|
| ① 痛点 | 采购卡在「不敢信」，不是「不够聪明」 | 20s | README 开头「我们不让模型给自己打分」 |
| ② 解法 | 判分与生成解耦：本地精确判分 + 模型只说人话 | 25s | `app/executor.py`、`solver_view()` 白名单 |
| ③ 证据 | 612 tests / 1200 SymPy 样本 / 2640 次留出 / 三档校准 12.8→52.8→92.8% | 30s | `docs/评测报告_12h.md`、`web/experiment.json` |
| ④ 商业路径 | 谁买、为什么现在买（见 §3） | 30s | 本文件 §3 |
| ⑤ 边界 | **主动报** 3 个知识点、模拟学生、未观察到可靠策略改善 | 15s | `README.md` §已知边界 |

**第 ⑤ 段千万别省**。主动报边界，是评委给你「诚实」标签的唯一机会，
也是全项目最贵的资产。一个敢报负结果的团队，说的正结果才有人信。

## 3. 技术 → 商业翻译（四条链路，每条都能指到代码）

| 我们做了什么 | 换成商业语言 | 谁付钱 |
|---|---|---|
| 判分 0 浮点、不让模型当裁判 | 对错可复核可回放 → 责任可界定 → **进校采购硬门槛** | 学校 / 教辅厂商 |
| 模型只说人话、判分与生成解耦 | 模型可换、不被供应商锁定；每次判分零模型调用 → **毛利结构更优** | 机构 IT / 采购 |
| 零外链、断电可演、本地引擎 | 数据不出域、内网私有化部署、无需云端 GPU → **合规入场券** | 校方 / 政企 |
| 掌握度 + `best_profile.json` 可 diff 可回滚 + 「为什么给你这道题」 | 从答题工具升级为**教学决策依据**，可解释、可 A/B、可版本管理 | 老师 / 教研 |

> 单位经济这条最硬，且完全由架构推出，不是预测：
> 判分不调模型 → 每次判分零推理成本；模型只生成话术 → token 少且可换最便宜的；
> 离线可跑 → 无云端 GPU 常驻。别编具体金额，讲**结构**。

## 4. 三层收入路径（近 → 远，别混着讲）

1. **近期 · To B 授权**：把判分内核 / 错因诊断 / 掌握度估计做成 SDK，
   卖给题库、教辅出版社、网校。这是仓库里**唯一已经硬化到 612 条测试**的东西，
   也不需要自己有流量——客户缺的正是「可复核的自动判分」。
2. **中期 · To 校 / To G 私有化**：零外链 + 断电可演 = 数据不出域、内网可部署，
   直接对应进校采购的合规门槛；再叠一层学情看板给教研，按校 / 按学期订阅。
3. **远期 · 教法评测流水线**：4×20 代真演化、2640 次留出、三档校准、9 行教法对照，
   本质是「怎么科学地判断一种教法有没有用」的方法论，可跨科目、跨客户复用。
   **这是估值故事，不是近期收入**，讲的时候别当成明年就能收钱。

## 5. 评委最可能戳的三问，这么接

### Q1「AI 家教一抓一把，凭什么是你们？」
**答**：不比谁更聪明，比谁判错能追责。别人卖效果，我们卖**可追责性**——
效果会随模型版本漂移，可追责性不会。

### Q2「才 3 个知识点，怎么商业化？」
**答**：现在验证的是**可信性**不是规模；四个模板覆盖整类「答案可精确判定」的题，
扩题是工程问题不是架构问题。而且明确拒答证明题、英语作文，
恰恰是采购方要的边界感——什么都能答的 AI 没人敢签字。

### Q3「演化没观察到可靠策略改善，那训练期图什么？」
**答**：**这题要主动抢着答**——
「我们卖的不是『保证教法有用』，是『能可靠地测出有没有用』。
敢把负结果原样写出来，正是这套评测可信的证据。」
把负结果变成卖点，这一句最加分。

## 6. 三条红线（一踩就毁人设）

1. **不编市场规模 / TAM / 用户数 / 营收预测**——没测过就不编，一问来源就穿；
2. **不说「替代老师」**，说「让老师敢用」——采购决策者是学校，把老师放对立面等于把客户吓跑；
3. **不藏负结果、不把 `is_mock` 数据当真结果**——
   `web/result.json` 已接真实数据，但 `0 个 p 值`、`未观察到可靠策略改善` 必须留在嘴边。
