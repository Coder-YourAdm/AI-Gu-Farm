# 完整方案：日新 · 智慧考研助手

> 从「养蛊机」到「一个会记住你的助教」。本文是可执行版，含公式、参数、日程、验收与答辩。
> 读完前 0 节约 60 秒，能对评委讲完整个产品。

---

## 0. 一页纸（60 秒版）

**问题**：考研数学最大的浪费不是"不会"，是"不知道自己哪里不会"，于是反复刷已经会的题；而通用 AI 讲题讲得又长又准，却不记得你上周在哪一步栽过。

**做法**：用养蛊机在开赛前把"怎么教"演化到最好，冻结成一份 profile；运行期只跑一个 AI，配三个可复核的引擎——精确判分、掌握度估计、复习排期；再叠加一层带证据链的记忆。教法周更，认识秒更。

**凭什么可信**：
- 判分不用模型（`Fraction` 精确算术），同一道题任何人任何时候算出的答案都一样；
- 每一道"为什么给你这题"都能点开：三个数字（掌握度 / 题目难度 / 上次错因）+ 一条记忆；
- 教学策略不是手调的，是 6 套里按"学生增益 − 交互成本"选出来的；
- 不会的题型直接说不做（`limits.refuse`），不硬编答案。

**一句话**：**不是让 AI 每天重学怎么教，而是让它开赛前把教法练到最好，之后每天只更新对你这个人的认识。**

## 1. 定位：三层「日新」

赛道主题是「日新 / 生生不息」。这个词很容易讲成口号，所以必须拆成三个能看见的层次：

| 层 | 什么在更新 | 频率 | 在哪看得见 |
|---|---|---|---|
| **教法** | 教学策略（4 个文本基因 + 5 个参数） | 每周离线重训 | profile 的版本号 `v20261114`，可 diff |
| **学生模型** | 每个 KC 的掌握度、题目难度、记忆强度 | 每次答题（秒级） | 大屏上的掌握度曲线、复习清单 |
| **记忆** | L1 事件 → L2 摘要 → L3 画像 | 会话结束 / 事实变化 | 时间轴：`11/10 错 → 11/12 独立对两次 → 今天复查 1 题` |

三层里，**只有第一层是"离线重"的**，后两层都在运行期实时发生。这就是"单 AI 服务"和"日新"能同时成立的原因。

> 反过来说：如果只做一层（比如只让 prompt 每周变），"日新"就退化成"周更"；如果三层都没有，那就只是个套壳聊天。

## 2. 边界：做什么、不做什么

**做**（答案可精确复核的题型）：

| 题型 | 判分方式 | 为什么能做 |
|---|---|---|
| 多项式 / 指数 / 高斯型定积分与反常积分 | 闭式解 + `Fraction` | 答案必为有理数 |
| 整数矩阵行列式（2–5 阶） | Bareiss 整数消元 | 结果必为整数，中间过程不引入分数 |
| 极限（有理式，同次） | 系数比 | 答案是有理数 |
| 多项式在整点的导数值 | 逐项求导 | 整数 |
| 几何级数求和 | `(r^{n+1}-1)/(r-1)` | 有理数 |
| 小整数矩阵的幂 / 迹 | 精确整数矩阵乘 | 元素有界 |
| 整数特征值的和与积 | 构造 `A = P D P⁻¹` | 迹与行列式是整数 |

**不做**（并写进 `limits.refuse`）：

- 证明题（"证明 f 在 [a,b] 上一致连续"）——没有唯一答案可判；
- 英语作文、政治大题——同上；
- 任何需要"看起来对"就给分的题。

> 这条边界不是能力不足的遮掩，而是**判分可信的前提**。答辩时主动说出来，比被问出来强十倍。

## 4. 两个 skill 与产物契约

```
[训练期 · 重 · 每周/题域变更时]
  prompt-evolver  →  best_profile.json  →  [运行期 · 轻 · 每句话]
                                              kaoyan-tutor
```

**铁律**：`kaoyan-tutor` 只读 `best_profile.json`，不读 `runs/`、不读 `history.jsonl`、不读参考答案表。
好处：学生端不可能泄漏参考值、换模型不影响产品、回滚只需换一个文件。

## 5. 学生模型：三个能手算的模型

### 5.1 掌握度：BKT（每个 KC 一组参数）

四个参数：`p_init` 初始掌握、`p_transit` 练一次就学会、`p_slip` 会却答错、`p_guess` 不会却蒙对。

```
答对:  p_known = p(1-slip) / ( p(1-slip) + (1-p)·guess )
       p_new   = p_known + (1-p_known)·transit
答错:  把上式里的 (1-slip)→slip，(guess)→(1-guess)，再更新
```

默认值（**人类常识值，不是拟合值**，答辩要这么说）：

| 参数 | 默认 | 理由 |
|---|---|---|
| `p_init` | 0.20 | 默认学生没学过 |
| `p_transit` | 0.15 | 讲一遍能会一小半 |
| `p_slip` | 0.10 | 会做也可能算错 |
| `p_guess` | 0.25 | 四种答案里蒙中一个 |

**升级规则（防"讨好型教学"）**：必须"无提示 + 独立 + 换一道同 KC 不同参数的题"再对一次，才升一级。学生说"我懂了"不算。

### 5.2 难度：Elo-lite

```
E = 1 / (1 + 10^((d_item − θ_student)/400))
d_item += K · (实际 − E)          # K=16
```

选题规则：在候选里挑 `|d_item − (θ + 0.1)|` 最小的——**略高于当前水平**（最近发展区），不是最难的题。

> 会被问："为什么不做最难的？" 答：**学习发生在最近发展区，不是挫败区。** 最难题只会让学生掉线。

### 5.3 记忆：SM-2 简化版（可换 py-fsrs）

```
答对: interval = interval × 1.7 × ease      ease 随连续答对微增
答错: interval = 1 天，ease −0.2（下限 1.3）
```

接口设计成可替换：`schedule.due(kc, now)`。正式版可无缝换 `open-spaced-repetition/py-fsrs`（MIT，纯离线）。

### 5.4 fitness：把"教得好"变成一个数

```
gain    = (post − pre) / (1 − pre)              # Hake 标准化增益
cost    = 0.3 × 题量/基准 + 0.7 × 提示次数/基准
fitness = gain − 0.25 × cost
```

**为什么必须减成本**：只加增益，演化一定选出"无限提示、把答案嚼碎"的策略——增益虚高、学生没学会。减掉交互成本，才能演化出"话少而准"。

## 6. 教学决策：五级提示 + 五类错因

### 6.1 提示梯度（一级一级给，不许跳）

| 级 | 动作 | 触发条件 | 例子 |
|---|---|---|---|
| L1 `restate` | 重述题意，指出关键条件 | 第一次答错 | "题目给的是 0 到 ∞，你要的积分区间对吗？" |
| L2 `theorem` | 点出该用的定理/公式名 | 第二次答错 | "这种形式对应 Γ 函数的标准结论。" |
| L3 `step` | 给出下一步的中间量 | 第三次答错 | "先算 `n!` 和 `r^{n+1}`，再相除。" |
| L4 `example` | 换一个更小的同类例题 | 仍不会 | "先看 ∫₀^∞ x e^{-2x} dx 怎么做。" |
| L5 `answer` | 给答案 + 完整推导 | 明确要求或连续 5 次 | — |

**只到 L5 才给答案**，且全程记录"用到第几级"——这个数字既是 fitness 的成本项，也是学情报告里"你靠提示才做对"的证据。

### 6.2 错因分类（5 类，规则优先，模型兜底）

| 错因 | 判据 | 教学动作 |
|---|---|---|
| `sign` 符号错 | 答案 = −正确值，或分子符号反 | 让ta回代检验正负 |
| `calc` 计算错 | 结构对、数值错（分母差固定倍数） | 拆成两步重算 |
| `concept` 概念错 | 用错公式（如 gamma 用了 gaussian 的系数） | 回到定理，重讲条件 |
| `misread` 读题错 | 上下限/阶数/系数抄错 | 让ta把题干条件复述一遍 |
| `giveup` 放弃 | `unanswered` | 降难度，先建立一次成功 |

> 参考 `openai/prm800k` 的三态标注（正/中/负）思路：**步级判定比结果判定更能定位问题**。我们不训练 PRM，只借它的"逐步标注"语言。

## 7. 记忆层：可审计，不是黑箱

### 7.1 三层

| 层 | 内容 | 写入时机 | 能否改 |
|---|---|---|---|
| L1 事件 | 每答一题一条（含提示级别、错因、耗时） | 即时 | 只追加，永不改 |
| L2 摘要 | 一次会话 3–5 句：学了什么、卡在哪、下次先做什么 | 会话结束 | 可重写（保留旧版） |
| L3 画像 | 稳定事实（目标院校、基础、时间预算、顽固错因） | 事实出现/变化 | 带证据与版本 |

### 7.2 检索打分（为什么这条记忆被用上）

```
score = 0.5·KC 相关 + 0.3·exp(−Δt/14) + 0.2·confidence
```

取 top-4 拼进上下文。**每次回答都能列出"我依据了哪几条"**，点开可看证据事件——这是回应"AI 记忆是黑箱"最直接的办法。

### 7.3 冲突与遗忘（这是"日新"的技术核心）

```json
{"k":"薄弱","v":"换元后忘记换上下限","conf":0.8,
 "src":["evt_0031","evt_0044"],"t":"2026-11-14","supersedes":"2026-11-10 的判断"}
```

- **不覆盖，追加**：新证据来了，旧判断标 `superseded_by`，仍可查；
- **自然遗忘**：`conf × exp(−30天无证据)`，低于 0.3 自动归档；
- **学生可删**：一条命令导出/删除全部记忆（合规要求，也是答辩加分项）。

## 8. 题域与 KC：8 个知识点，4 个已实现

| # | KC | 模板族 | 闭式解 / 判分 | 状态 |
|---|---|---|---|---|
| 1 | 极限 | `limit_rat` | 同次有理式 → 系数比 | 待实现 |
| 2 | 一元微分 | `deriv_at` | 多项式在整点导数 | 待实现 |
| 3 | 定积分 | `poly` | `Σ aᵢ(u^{i+1}−l^{i+1})/(i+1)` | **已实现** |
| 4 | 反常积分 | `gamma` / `gaussian_odd` | `c·n!/r^{n+1}` / `c·k!/(2r^{k+1})` | **已实现** |
| 5 | 数项级数 | `geom_series` | `(r^{n+1}−1)/(r−1)` | 待实现 |
| 6 | 行列式 | `det` | Bareiss 整数消元 | **已实现** |
| 7 | 矩阵幂 | `matrix_pow` | 精确整数矩阵乘，取元素/迹 | 待实现 |
| 8 | 特征值 | `eig_sum` | 由 `A=PDP⁻¹` 构造，问 λ₁+λ₂ 或 λ₁λ₂ | 待实现 |

**新增一族的成本**：约 20 行实现 + 20 条测试 + 1 次 `tools/sympy_crosscheck.py` 交叉验证，合计 45–60 分钟。四族正好一个下午。

**难度分档**（用参数范围控制，不用改代码）：

| 档 | 积分参数 | 行列式 | 适用 |
|---|---|---|---|
| T1 | `n≤3, r≤3` | 2 阶，元素 ≤5 | 诊断 / 建立信心 |
| T2 | `n≤6, r≤6` | 3 阶，元素 ≤9 | 主力练习 |
| T3 | `n≤9, r≤8` | 4–5 阶，元素含负 | 冲刺 / 挑战 |

**版权提醒**：考研真题整卷受版权保护，**不要整卷搬进仓库**。你们最强的其实是"能无限自造且答案精确"——这比搬运真题既安全又更有说服力。教材习题改编也要注明来源。

## 9. 评测：四组对照 + 三个必须报的诚实数字

### 9.1 指标定义

| 指标 | 定义 | 期望方向 |
|---|---|---|
| 标准化增益 `gain` | `(post−pre)/(1−pre)` | 高 |
| 题量效率 | 达到掌握度 0.95 所需题数 | 低 |
| 首题命中率 | 新会话第一题落在最弱 KC 的比例 | 高（有记忆 > 无记忆） |
| 校准 Brier | `mean((预测正确率−实际)²)`，10 桶 | 低 |
| 提示依赖度 | 平均用到第几级提示 | 低 |
| 成本 | 每题交互轮次 | 低 |

### 9.2 四组对照（固定种子，离线可复现）

| # | 对照 | 自变量 | 主指标 |
|---|---|---|---|
| ① | 自适应难度 vs 固定 T2 | 选题 | 题量效率 |
| ② | 梯度提示 vs 直接给答案 | 提示 | 后测独立正确率 |
| ③ | 有记忆 vs 无记忆 | 上下文 | 首题命中率 |
| ④ | 演化策略 vs 手写策略 | 策略来源 | `gain − 0.25·cost` |

### 9.3 三个必须同时报的数字

1. **n = 3 个模拟学生 × 每人 30 题**——样本小，写清楚；
2. **模拟学生有偏**：它的"会忘"是按我们的假设写的，所以只能证明"策略在模型内更优"；
3. **题域窄**：只做可精确判分的题型。

> 不报 p 值。n=3 时报显著性是在骗人；报原始配对差 + 一句"不做显著性主张"更专业。

| 20–22h | 全员 | 四组对照跑完 + 写评测报告 | 报告里三个诚实数字齐全 |

## 13. 开源参考：借什么、不借什么

### 13.1 Prompt 优化这一支（与我们最像）

| 仓库 | 许可证 | 借什么 | 不借什么 |
|---|---|---|---|
| [`stanfordnlp/dspy`](https://github.com/stanfordnlp/dspy) | MIT | **"编译一次、产出制品"**的范式：`compile()` 出 JSON，模型换版就重编译 | 它的优化目标是**单轮任务的标注集**，我们是多轮交互的增益，套不上 |
| [`gepa-ai/gepa`](https://github.com/gepa-ai/gepa) | Apache-2.0 | **反射式演化 + ASI**：把失败原因文本喂回变异，比纯随机变异省调用（官方称比 RL 省 90× 成本） | 我们没有"标准答案集"，fitness 来自模拟学生轨迹 |
| [`zou-group/textgrad`](https://github.com/zou-group/textgrad) | MIT | "自然语言当梯度"的表达方式，用于写变异提示 | 研究级，工程化弱，比赛期不接 |

> 这三个是最好的"同类对照"。答辩被问"你和 DSPy/GEPA 什么关系"，标准答法：
> **"同属'编译一次、产出制品'的范式；区别是我们的 fitness 是学生增益而不是标注准确率，所以我们自研了引擎，但借鉴了 GEPA 的 ASI 反馈做变异。"**

### 13.2 教学法与自适应

| 仓库 | 许可证 | 借什么 | 不借什么 |
|---|---|---|---|
| [`janestreet/agent_skills`](https://github.com/janestreet/agent_skills) `socratic-tutor` | MIT | **教学协议**：3–5 题诊断 → 4–10 子技能按 0–5 分级 → 一次只问一题 → 间隔复习 → 终评；"等级必须挣来" | 纯英文、无判分 |
| [`CAHLR/OATutor`](https://github.com/CAHLR/OATutor) | 代码开源 / 内容 CC BY 4.0 | **BKT + 知识组件 + hint→scaffold→solution 梯度 + 选题启发式**（CHI'23） | React + Firebase 架构、英文教材内容 |
| [`pykt-team/pykt-toolkit`](https://github.com/pykt-team/pykt-toolkit) | MIT | 日后有真实日志时换 DKT/AKT（有标准数据集与 baseline） | 现在用不上：要训练数据、不可解释 |
| [`openai/prm800k`](https://github.com/openai/prm800k) | 见仓库 LICENSE | **步级三态标注**（正/中/负）的语言，用于错因定位设计 | 不训练 PRM（80 万条标注与我们无关） |

### 13.3 记忆与复习

| 仓库 | 许可证 | 借什么 | 不借什么 |
|---|---|---|---|
| [`open-spaced-repetition/py-fsrs`](https://github.com/open-spaced-repetition/py-fsrs) | MIT | **离线 DSR 记忆模型**，`Scheduler/Card/ReviewLog` 可 JSON 序列化 | 比赛期先用 30 行 SM-2，接口留好 |
| [`HKUDS/DeepTutor`](https://github.com/HKUDS/DeepTutor) | Apache-2.0 | **L1/L2/L3 三层记忆 + Memory Graph 溯源**的设计语言；Quiz + Mastery Path 的产品形态 | 整套重栈（RAG + 前端 + 多向量库），接不起 |
| [`mem0ai/mem0`](https://github.com/mem0ai/mem0) | Apache-2.0 核心 | **"提取 + 多信号检索"**（语义 / 关键词 / 实体三路并行） | 托管服务；我们 60 行 top-k 够用 |
| Zep / Graphiti | Apache-2.0 | **时序知识图谱**：不覆盖，追加带时间戳的边（我们的 `supersedes` 就是这个思想的轻量版） | 需要图数据库，运维成本高 |

**一句话**：协议抄 Jane Street，算法抄 OATutor，记忆抄 py-fsrs，分层学 DeepTutor，范式对照 DSPy/GEPA，重依赖一个都不接。

## 14. 答辩 12 问

| # | 问题 | 答法 |
|---|---|---|
| 1 | 和教育类 App 有何不同？ | 判分不用模型、策略是选出来的、记忆带证据链。三件都能当场点开。 |
| 2 | 凭什么说它教得好？ | 四组离线对照 + 固定种子；报原始数字，不报 p 值。 |
| 3 | 模拟学生不是真人，有意义吗？ | 只能证明"模型内更优"；真人只做了 n=1，写在报告第一页。 |
| 4 | 和 DSPy / GEPA 什么关系？ | 同属"编译一次、产出制品"；fitness 不同（学生增益 vs 标注准确率），且借鉴了 ASI 做变异。 |
| 5 | 为什么不用微调？ | 我们没有万级标注；且微调后判分链路不可解释，与"可复核"冲突。 |
| 6 | 学生会不会变懒？ | 升级必须无提示独立答对两次；直接给答案的策略被成本项罚掉。 |
| 7 | 题目是不是背过答案？ | 发给学生端的只有 `type/statement/answer_format` 三键，`reference` 永不外发（已有测试锁住）。 |
| 8 | 数据/隐私？ | 全本地 JSON/SQLite，断网可演示；记忆可一键导出与删除。 |
| 9 | 只能做数学？ | 只做"答案能精确复核"的题；作文、证明不做，做了就是骗人。 |
| 10 | 记忆会不会记错？ | 每条带 `src` 证据与 `supersedes`；可回放、可删、可纠。 |
| 11 | 现场能看它进化吗？ | 主路径是"周更"；如果有要求，备用 3 个体 1 代、90 秒的小演化。 |
| 12 | 下一步？ | KC 扩到考研数学一全纲，接 30 名真实学生做 A/B，把"周更"跑成真正的闭环。 |

## 15. 风险与合规

| 类别 | 风险 | 止损 |
|---|---|---|
| 时间 | 24h 做不完 | 砍掉演化，只留 A 档（2 KC + 闭环 + 页面），叙事改讲"下一步" |
| 技术 | 模拟学生变"送分童子"（所有 gain > 0.8） | 加"会忘 + 会蒙"噪声重跑；仍失真就只报排序不报绝对值 |
| 技术 | 新模板族出 bug | 每族必须过 `sympy_crosscheck`，不过不进题池 |
| 现场 | 断网 | 静态页 + 本地 JSON + `app/serve.py`，零外链 |
| 版权 | 真题整卷搬运 | 只用自命题；教材改编注明来源 |
| 合规 | 学生数据 | 本地存储、可导出、可删除；不采集身份信息 |
| 伦理 | 变成代写/代做 | 只给"下一步提示"，不输出完整作业答案；L5 只在明确要求时触发 |
