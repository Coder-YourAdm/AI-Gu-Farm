# 先读我 · 这个包怎么核

这个包只解决一件事：**页面上每一个数字，你都能自己算一遍，不需要相信我们**。

不用装环境、不用跑模型、不用联网。三步，三分钟。

---

## 第 1 步（30 秒）— 看数字从哪来

打开 `01_数字对照表.md`。每张表的左边是页面上的数字，中间是**重算方式**，
右边是重算结果与页面值，最后一列是 `✓` 或 `✗`。

**关键点：表里的数不是抄页面的。** 它们是拿 `runs/*.jsonl` 的原始调用记录
重新算出来的，再和页面值对比。所以一个 `✓` 意味着两条独立路径得到同一个数。

如果哪天有人改了页面上的数，这张表会变成 `✗`，而不是跟着一起变。

## 第 2 步（1 分钟）— 自己跑一遍

```bash
python tools/check_web_data.py        # 确认交付数据没被顶掉，约 2 秒
python tools/build_evidence.py        # 重新生成本包，会重算所有数字
```

第二条命令如果输出「三处数据的重算值与页面值全部一致」，说明这个包没有被手改过。
任何一条对不上，它会直接打印 `✗` 并以退出码 1 结束。

逐条复现的命令在 `03_复现命令.md`，每条都是独立可跑的。

## 第 3 步（30 秒）— 确认是真模型跑的

打开任意一份 `.json` 的头部，看两个字段：

```json
"backend": "real",
"is_mock": false
```

**这两个字段由证据文件写，改页面改不掉。** 页面顶部的 `REAL 真模型` 绿标读的就是它；
如果是 `is_mock: true`，页面会挂红色 `MOCK` 标，并且数据不得进结论。

对应的 `manifest.json` 里还有 `config_sha256` 与 `prompts_sha256`：同样的配置和提示词
才能重跑出同一批数——这是「除条件外零参数差异」的机器可验证形式。

## 这三趟数据分别是什么

| 页面 | 数据来源 | 一句话 |
|---|---|---|
| 演化大屏 | `E_real_20261114` · 21 代 · 724 次调用 | 冠军从头到尾 7.00，一次没变 |
| 双跑对照 | `demo_pair_calib` · 20 题 × 2 趟 | 20/20 → 19/19，判定 `no_change` |
| 留出结果 | `E_real_20261114_r1/r2/r3` · 3 血脉 × 20 题 × 3 趟 | 19–20/20，level `none` |

## 这轮实验能证明什么、不能证明什么

**能证明的**

- 演化主循环在真模型上跑完了 21 代、724 次调用，每一代都留下了逐个体分数与调用 token
- 留出集（20 道从未参与演化的题）上，末代冠军没有稳定超过最好的祖先
- 上述每条结论都能顺着 `run_id` 查到原始调用记录，一题一行

**不能证明的**

- **不能证明"演化无效"。** 这轮的固定题库第 1 代就有人拿满，之后没有任何个体超过它
  —— 是**这套题测不出变强**，不是模型不会变强。天花板效应会让对照失效，
  这一条已写进大屏顶部的横幅，不是事后补的解释。
- **不能当成 E/F 对照组的结论。** E/F 正式六趟由 B8 值守执行，本包里的三趟
  （`E_real_*`）是交付前的真跑验证，不是实验对照数据。

## 一个必须交代的坑

`runs/demo_pair_calib/calls_pass2.jsonl` 是早期格式，**没有 `infra` 字段**，
第 11 题（K11）因推理吃光 6000 token 被截断，这条信息只写在 `reason` 文本里。

所以重算时如果只认 `infra` 字段，会把 19/19 算成 19/20 ——
等于把「额度不够」记成「模型不会」。这是本项目最不该犯的错，
`tools/build_evidence.py` 里 `is_infra()` 同时认字段和文本，对照表里也标了这段说明。
