# 复现命令

每条数字都能用一条命令重跑出来。都在仓库根目录执行。

## 0. 先确认交付数据还在（任何时候都能跑，约 2 秒）

```bash
python tools/check_web_data.py
```

退出码 0 = 三份数据与交付基线一致。非 0 会打印恢复命令。

## 1. 大屏的 21 代 / 724 次调用

```bash
python -c "
import json
rs=[json.loads(l) for l in open('runs/E_real_20261114/history.jsonl',encoding='utf-8') if l.strip()]
print('代数', len(rs), '调用', sum(r['usage']['call_count'] for r in rs))
"
```

## 2. 双跑的 20/20 → 19/19

```bash
python -c "
import json
for n in (1,2):
    rows=[json.loads(l) for l in open(f'runs/demo_pair_calib/calls_pass{n}.jsonl',encoding='utf-8') if l.strip()]
    ok=sum(1 for r in rows if r['correct'] and not r['infra'])
    print(f'pass{n}: {ok}/{len(rows)}  infra={sum(1 for r in rows if r["infra"])}')
"
```

## 3. 留出 19–20/20

```bash
python -c "
import json
from collections import defaultdict
for i in (1,2,3):
    d=defaultdict(lambda:[0,0])
    for l in open(f'runs/eval_20261114_083923/calls_r{i}.jsonl',encoding='utf-8'):
        r=json.loads(l)
        if r.get('infra'): continue
        d[r['lineage']][1]+=1
        if r['correct']: d[r['lineage']][0]+=1
    print(f'r{i}', dict(d))
"
```
