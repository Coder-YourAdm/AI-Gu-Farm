# history · 历史与交接存档

> **这里的文件一个都没删**：只是从仓库根目录 / `../docs/` 搬进来，内容逐字节保留。
> 它们是**决策留痕与史料**，不是开工依据。当前执行入口只有
> [`../docs/00_项目总纲.md`](../docs/00_项目总纲.md) 与 [`README.md`](../README.md)。

## 为什么单独放一个目录

根目录曾经散着 13 份「给 A 核对 / 给 B 交接 / v5 执行清单」这类一次性文档，
和 README 混在第一屏，找当前方案要翻半天。现在按用途分层：

| 层 | 位置 | 用途 |
| --- | --- | --- |
| 权威 | `README.md`、`../docs/00_项目总纲.md` 等 | 开工只看这些 |
| 契约与证据 | `../docs/` | 冻结契约、评测报告、交付简报 |
| 演示资产 | `../docs/demo/`、`web/` | 页面、截图、自检脚本 |
| **史料** | **`history/`（本目录）** | 追溯「当时为什么这么定」 |
| 规格沿革 | `方案/`、`方案/历史版本/` | v1–v5 大纲与历次复核（本来就是独立目录，未移动） |

## 还能找回旧路径吗

能。移动在 Git 里就是一次 rename，任何历史提交都能 `git show <commit>:<旧路径>` 取回；
若要恢复目录结构，把对应文件 `git mv` 回原位置即可。
