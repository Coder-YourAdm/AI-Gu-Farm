### ⚠️ 一条必须知道的渲染约束（实测踩到的坑）

`prompts/setter.md` 里有题面模板语法 `params={coeffs:[a0,...,ad],lower:l,upper:u}`。
这串花括号会被 Python 的 `str.format()` 当成占位符，**直接 `KeyError: 'coeffs'` 崩掉**。

**所以这五份 prompt 只能用 `str.replace()` 渲染，不能用 `.format()` 或 f-string。**

```python
# 对
text = setter_md.replace("{set_prompt}", genes["set_prompt"])

# 错 —— KeyError: 'coeffs'
text = setter_md.format(set_prompt=genes["set_prompt"])

# 错 —— 同样会解析花括号
text = f"...{setter_md}..."
```

规格原文就是这样，不能改（改了就和 §3.2 不一致）。`tests/test_prompts.py::test_must_render_with_replace_not_format` 已经把这个约束固定住——谁把渲染改成 `.format()`，测试立刻报错。

各文件的占位符清单：

| 文件 | 占位符 |
|---|---|
| `setter.md` | `{set_prompt}` |
| `solver.md` | `{solve_prompt}`、`{check_instruction}`（`self_check=false` 时替换为空串） |
| `crossover.md` | `{parent_a}`、`{parent_b}`（**名字待 B 确认**，改只需 Ctrl+H） |
| `mutate.md` | `{parent}`、`{field_to_mutate}`（**名字待 B 确认**） |
