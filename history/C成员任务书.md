## 1 C 的唯一硬约束：export 白名单（违反等于交白卷）

规格 §8 L516 原文：

> 向浏览器公开的 export **只白名单提取**题面、已完成题目的展示答案（如有）、曲线、分数和运行说明；**测试题集正文、完整快照及原始请求不放到静态根目录**。

落到代码上，三条不可协商：

1. **白名单实现，不是黑名单**：`export.py` 里先定义允许字段集合，逐字段 copy；**禁止** `dict(rec)`、`{**rec}`、`json.dump(rec)` 这类整体透传
2. **`reference` 字段永不出现**：`Task.reference`（§2.2）是答案，一旦进 `web/history.json`，任何人打开浏览器就能看到标准答案
3. **`holdout.jsonl` 的题面永不出现**：留出集是唯一"没被演化污染"的证据，漏一道，整份留出评测结论失效

**验收动作**（自己就能做，不用等人）：

```bash
python -c "import json;d=json.load(open('web/history.json',encoding='utf-8'));s=json.dumps(d,ensure_ascii=False);print('reference 出现次数:',s.count('reference'))"
# 必须为 0
```

再跑一条 grep，确认留出题面没进静态目录：

```bash
grep -c "holdout" web/*.json web/*.html
```

**出处**：§1 L26「公开历史与结果页；过滤参考值和非公开数据」、§8 L460–484（history 结构）、§8 L516（白名单）

**怎么干**

1. 读 `runs/<run_id>/history.jsonl`，逐行 `json.loads`，**只接受 `status=="completed"` 的代**（§8 L512：不把半行当一代）

## 2.6 C-9 双跑链路（P0，2026-11-13 新增）

**出处**：选手手册「日新主题赛道」——「现场跑两次」「要讲清三件事：比什么指标两次各多少 / 学到了什么 / 怎么回退」

### 为什么必须有

`index.html` 展示的是「我已经跑完 20 代」。赛道要的是「你现在跑一次，我再跑一次，你看第二次好在哪」。**这两件事不是同一个东西**，前者再漂亮也过不了现场那一关。

### 做出来的东西

| 文件 | 作用 | 状态 |
|---|---|---|
| `app/evolve_schema.py` | 双跑数据契约（与 B 的唯一对接点） | ✅ 完成 |
| `app/demo.py` | 双跑编排：pass1 → 学习 → pass2 → 导出 + `rollback` 子命令 | ✅ 完成（mock 可跑） |
| `web/evolve.html` | 双跑对照页：指标 / 逐题对照 / 学到了什么 / 回退条 | ✅ 完成 |
| `data/verify_bank.json` | 10 道冻结验证题，题面与期望值逐字取自附录 A | ✅ 完成 |
| `app/serve.py --allow-rollback` | 页面按钮直接触发真实回退 | ✅ 完成 |
| `双跑演示手册.md` | 三行进化说明 + 90 秒流程 + 三条防线 | ✅ 完成 |

### 三个设计决定（已定，不再讨论）

1. **单次运行 = 1 个体 × 10 道冻结题**，不是整代 78 次调用。理由：整代 2–3 分钟，3 代 6–8 分钟，赛道上限是 1 分钟，必超时
2. **学的是族级规则**，不是精英基因。理由：规则能用一句中文念给评委听，基因 diff 讲不清
3. **回退靠 state 快照**，代码与 prompts 零改动。理由：赛道明确禁止人改这三样，所以「学」只能落在 state

### 验收

```bash
python -m app.demo pair --pair demo_pair_dev --backend mock   # 4/10 → 8/10
python app/serve.py --port 8000 --allow-rollback
# 页面点回退 → status 显示 version=v0_seed rules=0 memories=0
```

**真跑验收（等 A/B 交付后）**：`--backend real` 单次 ≤40 秒；`frozen.identical_across_passes` 必须为 `true`，为 `false` 则本次结果不可用。

### 依赖 A/B 的两件事（已写进手册 §5）

- A 提供 `app/executor.py` 的 `judge(task, answer)`；B 提供 `app/llm.py` 的 `complete(messages)`
- 缺任何一个 `--backend real` 会直接退出并说明缺谁，不静默降级
